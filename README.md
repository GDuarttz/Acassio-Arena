# ⚽ Acassio Arena - Landing Page

Landing page institucional e moderna desenvolvida para o complexo esportivo **Acassio Arena**, localizado em Governador Celso Ramos - SC. O projeto reúne informações sobre as quadras de Futebol Society, CT de Areia, Centro de Lutas, Escolinha de Futebol, Gastronomia e Locação para Eventos.

🚀 **Acesse o site ao vivo:** [https://gduarttz.github.io/Acassio-Arena/](https://gduarttz.github.io/Acassio-Arena/)

---

## 📌 Funcionalidades

- **Design Dark Premium:** Interface moderna com foco em alto contraste, legibilidade e identidade visual neon/esportiva.
- **Totalmente Responsivo:** Layout fluido otimizado para dispositivos móveis, tablets e computadores.
- **Foco em Conversão (CTAs):** Botões diretos para o WhatsApp em cada seção com **mensagens pré-formatadas** personalizadas.
- **Prova Social Integrada:** Seção dedicada com avaliações reais e nota do **Google Maps**.
- **Otimização para Redes Sociais (SEO / Open Graph):** Pré-visualização personalizada com imagem de capa ao compartilhar o link no WhatsApp e Instagram.
- **Acessibilidade e Desempenho:** Carregamento otimizado de imagens (`lazy loading`), zoom de tela liberado e micro-interações em CSS leve.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica do projeto.
- **Tailwind CSS:** Estilização responsiva e utilitária via CDN.
- **JavaScript (ES6+):** Controle interativo do menu mobile e comportamento de navegação.
- **FontAwesome 6:** Ícones vetoriais integrados.
- **Google Fonts:** Tipografias *Inter* e *Montserrat*.
- **GitHub Pages:** Hospedagem e deploy contínuo da aplicação.
